# 创作场景路由（Scenario Routing）

## 1. 核心原则

小红书内容没有唯一正确的设计模板。

创作前应先理解内容、读者、素材和发布目的，
再决定叙事方式、文字风格、图片比例、字体、
配色、信息密度和版面结构。

像内容创作者一样思考，
像专业设计师一样组织信息，
像真实的人一样表达。

禁止将所有主题机械地套入同一种版式。

## 2. 场景识别

接到创作任务后，先在内部判断：

1. 用户想表达什么？
2. 读者为什么会停下来阅读？
3. 内容主要依赖照片、文字、截图还是数据？
4. 内容属于经验、知识、观点还是操作教程？
5. 读者看完后应该获得什么？

根据判断选择一个主要创作场景。

混合内容允许使用多个场景策略，但必须保持
整套图文的叙事主线和视觉一致性。

用户明确指定的风格、字体、尺寸、页数及
内容要求优先于场景默认配置。

## 3. 生活记录 PLOG

### 内容定位

记录普通生活中的具体瞬间、个人观察和感受。
不强行把日常生活包装成攻略、知识或人生哲理。

### 素材策略

- 优先使用用户真实拍摄的生活照片。
- 保留照片原有光线、色彩和生活细节。
- 允许适度裁切、调色和重新构图。
- 外部或生成素材不得冒充用户真实经历。

### 文案策略

- 使用自然的短句和具体生活细节。
- 可以有情绪，但不刻意煽情。
- 不强行总结生活意义。
- 避免虚构时间、地点、人物和经历。

### 视觉策略

- 默认优先考虑3:4竖版。
- 照片为主，文字为辅。
- 可以使用全幅照片、双图、错落构图。
- 字体和配色根据照片气质选择。
- 不强制每页有标题、页码或说明标签。
- 不堆叠卡通贴纸、打卡标签和装饰元素。

### 推荐叙事

一个生活瞬间 → 几个真实细节 → 自然结束。

## 4. 旅行日记（Travel Diary）

### 内容定位

以真实见闻、旅行体验和实用发现为核心。

区分旅行日记与旅行攻略：
日记强调体验，攻略强调信息和可执行性。

### 素材策略

- 优先使用真实风景、街道、建筑和旅行照片。
- 需要路线时使用准确地图或路线示意。
- 不虚构目的地、交通时间、价格和消费经历。
- 不使用生成图片冒充真实景点照片。

### 文案策略

- 保留具体见闻、细节和真实感受。
- 实用信息应准确，并有明确适用条件。
- 不强行使用“宝藏景点”“人生必去”等套话。

### 视觉策略

- 照片具有较高视觉权重。
- 封面可以用一张强视觉照片配简短标题。
- 正文采用大小照片交替形成阅读节奏。
- 配色可以从真实照片中提取。
- 不机械使用白底、红框和数字编号。

### 推荐叙事

出发 → 沿途见闻 → 核心体验 → 实用发现。

## 5. 好物分享（Product Sharing）

### 内容定位

围绕商品解决的问题、适用场景、真实特点
和使用体验展开。

### 素材策略

- 优先使用真实商品照片和使用场景。
- 展示有价值的外观、尺寸、结构和功能细节。
- 不改变商品实际外观、材质和性能。
- 没有真实使用经历时，不伪造测评或购买体验。

### 文案策略

- 用具体特点替代空泛赞美。
- 有优点和局限时直接说明。
- 不编造使用时间、购买价格、销量和评价。
- 不使用未经证实的功效、材质或性能宣称。
- 商业合作按适用规则进行披露。

### 视觉策略

- 商品或实际使用场景是视觉主体。
- 允许使用近景、细节图和对比构图。
- 避免传统电商促销海报式设计。
- 不默认添加价格爆炸贴、夸张感叹号、
  营销徽章和大量卖点标签。

### 推荐叙事

为什么关注它 → 商品特点 → 使用场景 →
适合什么人。

## 6. 知识科普（Knowledge Explainer）

### 内容定位

将复杂知识解释得准确、直观、容易理解。

### 素材策略

- 优先使用可靠的原始资料、文献和数据。
- 根据需要制作准确的示意图、机制图和图表。
- 科研图片、实验结果和统计数据不得伪造。
- 将已证实结论、研究假设和个人推测区分开。

### 文案策略

- 从一个具体问题或现象切入。
- 先解释读者能理解的部分，再展开原理。
- 专业术语首次出现时提供必要解释。
- 不为了吸引流量夸大研究结论。

### 视觉策略

- 强调明确的信息层级。
- 可以采用机制图、结构图和关系图。
- 配色用于表达分类和逻辑关系。
- 避免无意义的装饰插画和复杂信息卡片。
- 必要的文献来源、单位和图例应保留。

### 推荐叙事

现象 → 问题 → 原理 → 证据 → 结论。

## 7. 行业观点（Opinion）

### 内容定位

围绕一个明确问题提出判断，展示推导过程、
事实依据和有价值的个人观察。

### 素材策略

- 可以使用真实新闻截图、招聘信息、
  行业报告、公开数据和其他相关证据。
- 时效性信息应先核查来源。
- 不伪造引用、新闻、数据和他人观点。

### 文案策略

- 封面突出一个问题、发现或核心判断。
- 让读者看到观点是怎样推导出来的。
- 减少空泛总结和未经支撑的宏大结论。
- 不刻意制造焦虑或虚构对立。
- 不使用习惯性防御式表达。
- 需要表达不确定性时，直接说清原因和条件。

### 视觉策略

- 文字可以成为主要视觉元素。
- 采用编辑式排版、清晰段落和充足留白。
- 重要数字和关键词可以适度强调。
- 有证据时插入真实素材。
- 不强制使用插画或每页都放图片。

### 推荐叙事

问题 → 观察 → 证据 → 推导 → 判断。

## 8. 实操教程（Tutorial / SOP）

### 内容定位

让读者能够根据图文实际完成一项操作。

### 素材策略

- 使用真实操作截图、真实页面和真实数据。
- 优先使用用户提供的素材。
- 缺失截图时使用可靠的公开操作指南，
  或直接通过文字说明。
- 禁止生成式AI重绘真实操作页面。
- 对隐私信息做不透明遮盖。

### 文案策略

- 按实际操作顺序组织内容。
- 每页解决一个主要操作问题。
- 使用自然数字编号和准确的按钮名称。
- 保留必要的操作条件、费用和限制。
- 删除制作说明和无阅读价值的小标注。

### 视觉策略

- 文字为主，截图为辅。
- 默认可采用9:16竖版。
- 白底、深色文字、少量暗红色强调。
- 中文字体优先考虑仿宋_GB2312。
- 红框和箭头仅用于确有必要的操作定位。
- 截图必须清晰，避免过度缩小。

### 推荐叙事

准备 → 入口 → 选择 → 填写 →
核查 → 提交 → 结果。

## 9. 阅读分享（Reading Notes）

### 内容定位

表达对一本书、一篇文章或一个观点的理解，
而不是简单堆砌摘抄和金句。

### 素材策略

- 使用真实书籍、封面及合法引用的内容。
- 区分作者原文、内容概括和个人理解。
- 不编造书中原话、页码和作者观点。

### 文案策略

- 可以从一个值得思考的问题切入。
- 摘录应服务于解释和个人思考。
- 不强行把每本书总结为固定的若干条道理。
- 避免鸡汤式语言和机械升华。

### 视觉策略

- 可采用书页感、杂志感或原生笔记感。
- 文字为主，摄影为辅。
- 保持舒适的行距、段落和阅读节奏。
- 引用内容与个人理解具有清晰区分。

### 推荐叙事

问题 → 原文或观点 → 理解 → 延伸思考。

## 10. 数据分析（Data Storytelling）

### 内容定位

用数据解释一个具体问题，
让读者看懂变化、差异及其可能原因。

### 素材策略

- 使用可追溯的真实数据。
- 演示数据必须明确其示例性质。
- 核对数据口径、时间范围、单位和计算逻辑。
- 不伪造统计结果、图表和数据来源。

### 文案策略

- 优先表达数据中值得关注的发现。
- 解释数字背后的含义。
- 区分相关性、因果关系和推测。
- 对证据不足的原因分析保留必要的不确定性。

### 视觉策略

- 根据数据关系选择合适的图表。
- 对比使用条形图，趋势使用折线图。
- 图表必须保留必要单位和数值说明。
- 使用颜色突出重要数据，而不是装饰图表。
- 避免3D图表、过多颜色和不必要的仪表盘。

### 推荐叙事

问题 → 数据 → 关键发现 → 解释 → 启示。

## 11. 混合场景处理

当内容同时属于多个场景时：

1. 确定主场景，作为整套内容的叙事基础。
2. 次场景只提供局部表达方法。
3. 统一字体体系、间距和视觉节奏。
4. 不要求每一页采用完全相同的构图。

例如：

- 旅行攻略：旅行摄影 + 实操信息。
- 科研日常：生活PLOG + 知识科普。
- 电商运营复盘：数据分析 + 行业观点。
- 读书生活记录：PLOG + 阅读分享。
- 好物测评：商品摄影 + 数据对比。

## 12. 自然表达规则

所有场景都必须遵循 editorial-voice.md。

减少机械式转折、自我辩护、空泛结论、
模板化开场、强行升华及营销式口号。

不要把用户提供的设计指令写进成品。

必要的风险、事实限制、来源、单位、商业披露
和操作条件应准确保留，并以自然方式表达。

不机械禁止某个连接词，而是删除没有信息价值
的表达。

## 13. 视觉设计工作流

1. 判断创作场景。
2. 盘点真实素材及内容依据。
3. 确定视觉方向。
4. 建立逐页内容计划。
5. 完成文案及排版。
6. 检查事实、隐私和技术问题。
7. 进行第二轮审美审查。
8. 修正后交付实际成品。

默认比例、字体和配色仅是起点，
应当根据本次内容和用户要求调整。

渲染工具服务于设计方案，
不得为了使用固定脚本而限制创作形式。

## 14. 最终审美审查

完成图片后，必须实际打开成品检查：

- 封面是否具有明确的阅读理由？
- 文字是否像真实创作者的表达？
- 素材是否真实、准确、适合公开？
- 是否存在无阅读价值的小标注？
- 是否仍然像商业PPT或默认AI模板？
- 字号、留白、构图和信息层级是否自然？
- 不同页面是否具有合理的阅读节奏？
- 缩小到手机屏幕后是否清晰？
- 是否存在隐私泄露、事实错误和文字溢出？

发现问题后进行修正，并再次检查。

## 15. 规则优先级

用户本次明确要求优先于设计默认值。

场景路由中的具体视觉策略优先于通用的
SOP字体、配色、截图比例和编号规则。

真实性、隐私保护、事实准确性、素材授权
和必要的内容披露适用于所有场景。

任何场景都不得以提高真实感为由，
伪造用户经历、截图、数据或事实。
