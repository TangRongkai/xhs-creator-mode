# 视觉系统：手机原生笔记 × 编辑式排版

从已确认的 14 页真实开店 SOP 中抽象而来，保留设计方法，不绑定原案例、品牌或截图。以下为可调整的起点，不是模板锁定。

## 画布和字号（1080×1920 基准）

- 背景：#FFFFFF 或 #FDFDFC；正文：#181818；辅助文字：#626262；强调：#B8172B；细线：#D9D7D3。
- 左右边距 72–88 px，顶部 64–90 px，底部 72–100 px。截图和正文沿同一条视觉网格对齐。主标题 62–76 px，正文 35–43 px，导语 35–39 px；页眉/页码可用 23–28 px，正文不能靠缩小来塞内容。按实际字体的字形和读屏效果微调。
- 优先仿宋_GB2312（检查实际字体文件及字形）；其次 FandolFang、其他可获得的仿宋。必要时用适合中文的衬线字体；英文字母和数字可用协调的清晰字体。不要把宋体或楷体谎称为仿宋。所有截图中的字体保留原样。
- 正文行间距约 1.35–1.55，段落间距 20–36 px，标题到内容留 32–64 px。数字左栏 70–95 px，步骤内容左对齐。自然换行，避免将单个字/标点落到下一行，英文长词优先完整保留，避免不必要的分割。
- 若使用页眉，保持简短，如「02 · 站点与主体」，配细灰线和短红线；页脚最多一行页码。用户要求无附加标签时省略页眉/页脚。避免为每个截图加“真实截图”“本人实操”等标签。

## 按内容选择布局

1. 封面：主标题 1–3 行，位置接近视觉中心。纯文字封面只放主题，可用两条细线构成秩序，不加图标和宣传小字。保持 3:4 等预览裁切下仍可读。
2. 单步骤页：标题、简短情境、一张关键截图（必要时裁取表单）、3–5 条编号操作。若图本身较高，可把文字置于前后。
3. 双步骤/证据页：先介绍操作，再插小图；随后进入下一个操作。通常不超过 2–3 张相互补充的局部截图。长表格可局部放大或分两页。
4. 选择比较页：两三种方案，用短段落、简洁表格或编号分支解释选择条件；表格仅当真正需要逐项对比，不用同质彩色卡片。
5. 纯文字页：资料清单、方法或隐私不便公开的步骤；利用短标题、数字和留白，不填充伪造页面或无关插画。
6. 结果页：以实际结果截图支撑对应事实，加简短下一步。结果状态必须和图一致。

## 节奏与取舍

一页应在手机上形成清楚的阅读路径：标题 → 关键操作 → 图证 → 下一步。文字为主不等于文字堆满；截图可在关键页占较大面积，但始终由文字解释其用途。图片与文字重复时，保留最能帮助读者定位控件的信息。正文红色通常只强调 1–3 个关键位置；不要把整段涂红，不加彩虹标签、圆角胶囊、阴影堆叠或卡通图标。少量细分隔线和适度空白胜过装饰。

## 二次审美核对

缩小看标题、字号与整体重量；放大看截图字段和红框。若看不到按钮文字，宁可裁切局部或拆页。相邻页面同一级标题、数字、页脚应视觉一致；内容不同的页可以有不同的截图位置与留白。低密度页不硬填内容，高密度页不硬缩字体。无误后才打包。
