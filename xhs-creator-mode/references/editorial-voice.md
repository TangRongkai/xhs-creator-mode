# 真实经验口吻与文案修订

写给第一次实际操作的人。用清晰的名词、平台原始按钮文案、必要的数值和具体动词。自然，不写万能模板开场、无根据的热闹语气或居高临下的劝说。

## 写法

- 「我当时」「我们当时」仅用于用户确实提供的经历；其他内容写成「选择」「可以」「需要」「建议」等。
- 一句话表达一个有效信息；短句和自然编号。关键字段直接使用页面原文；英文术语首次出现时附中文解释。
- 对有条件的政策直接写条件、适用对象、动作。费用有币种，账期有起算点，规则有适用市场。不将示例当普遍结论。
- 不编造用户观察；没有用户提到的感受就不写。不要以“最近很多朋友问”“我真的踩了很多坑”等虚构叙事制造人味。
- 规则、法律和风险确有必要时保留准确措辞。反对的是无价值的防御式句型，不是反对事实限定。

## 改写示例（不是固定文案）

| 避免 | 更自然的写法 |
|---|---|
| 虽然审核通过了，但不代表保证金已缴、商品已上架或已经出单。 | 收到过审邮件后，按后台要求完成保证金设置，再准备上架。 |
| 这张图只证明后台显示应缴90美元，不代表已经完成付款。 | 我们当时的后台显示应缴保证金 90 美元。 |
| 虽然可以免保证金，但这不代表回款会快。 | 选择90天豁免，结算周期设为订单送达后30个自然日（按该页面规则）。 |
| 这一步没有绝对标准，不是所有人都适合。 | 想回收退货，就先联系认证仓，确认质检、回收和重新发货的费用。 |
| 虽然精确匹配没有结果，但并不意味着没有商标风险。 | 精确检索后，再查近似拼写、发音、目标国家的有效商标及申请记录。 |
| 不能仅凭搜索为零保证商标合法。 | 发现可能混淆的在先权利，先核对或换名；正式使用前复核当地商标数据库。 |
| 这页刻意不放网页模拟图，也不展示个人后台数据。 | 删除整句；直接写申请时需准备的材料。 |
| 本人实操·官方认证本地退货仓选项 | 删除标签，正文写「官方认证仓」及其用途即可。 |
| 真实操作截图·2026.11／实操提交时间…… | 删除重复来源或无关时间；涉及活动有效期等有用日期时保留。 |
| 保姆级教程，小白闭眼冲！ | 跨境店注册流程／店铺入驻怎么填？ |

不是机械禁止所有「不」「但是」或所有小字。必要的禁止项、限制、步骤分支和真实出处仍然保留。判断标准是：删掉这句话或标签，读者的下一步行动或对事实的理解是否会受影响？若不会，通常删掉。
